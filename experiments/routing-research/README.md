Files that shipped permanently at the repo root from the pre-flatten
research sessions (2026-08-–09-09). These are **not product code** — they
are the receipts backing specific claims in `docs/design/FLEET-PLAN.md` and
`docs/design/CONCEPT.md` about MoE expert routing, cold-start price
prediction, and step3b routing history. Kept for provenance; not read at
runtime by anything in `spacepilot/`.

Each file is a self-contained JSON/CSV export from one of the internal
measurement sweeps; see the FLEET-PLAN doc for the sweep that produced
each. If you are looking for the *live* registry, that is
`spacepilot/registry/models/` and the generated
`spacepilot/web/registry.json` — not here.
