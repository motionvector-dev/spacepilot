T-01

Built for crews of agents

SpacePilot is agent-native, not agent-tolerant. Every capability in the studio is also a tool an AI can call — the UI and the swarm share one protocol.

Native MCP tool server

Twelve-plus FastMCP tools expose generation, assets, and telemetry to any MCP-speaking agent.

DocIR 2.0 edit protocol

Byte-exact, reversible patches. Agents edit the document, never the render — every change can be undone.

WebSocket PTY bridge

A live interactive shell and worker stream, so you can watch a remote GPU think in real time.

Token-gated spend

Every endpoint that burns compute or money requires a signed token. Read-only stays open.
