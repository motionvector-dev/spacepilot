Day 2

Setup, and knowing what the machine can run

The onboarding work landed as two probes and one registry. A browser can name the chip; only a process on the machine can ask the driver what a model may actually use. Both read the same model registry, so the public page and the installed app can never quote different numbers.

Hardware probe, rewritten

Reads chip, P/E core split, GPU core count, Metal family, free memory and free disk. No fallback constants — an unreadable field stays unknown and carries its reason.

The previous version queried machdep.cpu.brand_str, which does not exist, so every Mac reported as the literal string “Apple Silicon”.

Model registry

One YAML per model, one entry per download. The catalog is a view over it — a test fails if a second copy of the model list appears anywhere.

Variants name their files: Lightricks/LTX-Video is 236 GB whole and 5.9 GB for the checkpoint you want.

Compatibility engine

Separates can this machine ever run it from can it right now. Conflating them tells someone with 32 GB that a 4 GB model will not run because a browser is open.

Ceiling comes from Metal where Metal will answer, not from a fraction we picked.

Consent-first onboarding

Lists every fact it will read and names the commands, before reading any of them. A second gate precedes each download with size, source and licence restrictions written out.

shippedonboard-v2

Public model page

Answers on arrival, and for hardware you do not own. Every fact shows its confidence at the same size as the value.

No server behind it — the registry ships as static JSON with the rule constants inside.

Speed corpus

The number nobody publishes for Apple Silicon. One measured, three cited, five honestly empty.

Published benchmarks rarely state checkpoint or precision, and usually test quantised community builds — so most of what exists cannot be attributed to a specific variant.

Local generation

Speech runs on this machine today — Kokoro 82M, 4.6× realtime, measured. Video does not: pluto generate still goes to the cloud box.

Image and music are one integration each — mflux and mlx-audio both have working Apple Silicon ports.

What is still not true. The local-first claim holds for speech and nothing else. Eight of nine variants have no measured footprint or speed on any machine, so most verdicts rest on estimates that say so.
