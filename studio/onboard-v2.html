First, your permission.

SpacePilot picks models by what your machine can actually run. To do that it has to look at your machine. Here is exactly what it reads.

Read locally, once

  • Model and chip name
  • CPU core count and split
  • GPU name and core count
  • Total and free memory
  • Graphics backend and its memory ceiling
  • Free space where models are stored
  • Operating system and version

This runs on the SpacePilot server on this machine and the answer stays here. Nothing is uploaded, and no account is involved. You can see the raw reading at any point, and the commands behind it are ordinary sysctl and system_profiler calls.
