# SpacePilot

Inference orchestration across the machines you can reach — the one on your
desk, the ones on your network, and the ones you rent.

**This release is a placeholder.** It installs, prints its status, and does
nothing else. The working package will land here when it is ready.

```console
$ pip install spacepilot
$ spacepilot
SpacePilot is under active development and this release is a placeholder.
```
