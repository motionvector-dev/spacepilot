## Flight plan

One command per unflown entry above to fly it later, unattended:

- **Executors** (Edge0 35B/8B, muse-glimmer, qwen1-5-moe): `spacepilot run text
  --model <variant-id> --yes` then the L2R Gate 3 typed-task suite at
  `mvec-engine/benchmarks/l2r/` (NOT CONFIRMED: that directory does not exist
  in this checkout yet — see report). Measure: peak unified-memory RSS during
  generation, steady-state tok/s, and the Gate 3 typed-task pass rate.
- **Qwen3.5-35B-A3B Base**: needs a local 4-bit MLX requant first (`mlx_lm.convert
  --hf-path Qwen/Qwen3.5-35B-A3B-Base -q`) before it can fly at all on this
  fleet — the bf16 checkpoint does not fit. Measure the requant's peak memory
  and tok/s once quantized.
- **STT** (Voz, Align, distil-whisper, sensevoice, moonshine): `spacepilot run
  transcribe --model <variant-id> --input <fixture.wav> --yes`. Measure: peak
  RSS, realtime factor (RTF), and for Align specifically, word-timestamp error
  against a forced-alignment fixture.
- **audio** (Clear, Ear, Uhm): `spacepilot run audio --model <variant-id>
  --input <fixture.wav> --yes`. Measure: peak RSS and seconds-per-second-of-audio.
- **PII** (Redact): `spacepilot run classify --model desert-ant-redact-1
  --input <fixture.txt> --yes`. Measure: peak RSS, throughput, and catch rate
  against a labelled PII fixture (compare to the declared 88.8%).
- **lang-id / drafter / utility** (Tongue, Title, Clips, Emo, Gist, Shapes):
  same `spacepilot run classify|text` shape, scoped to each model's own
  input type. Measure: peak RSS and latency per call.

- **Ternary executors** (BitNet b1.58 2B4T packed/GGUF, Ternary Bonsai 8B
  unpacked/GGUF): runtime recipe is pending -- `bitnet.cpp`
  (github.com/microsoft/BitNet, commit 0b341e582afbf9e1011f24744b554c96a3477eb5
  on main, checked 2026-09-10, MIT) for the two BitNet variants, and Prism
  ML's `llama.cpp` fork (PrismML-Eng/llama.cpp, `prism` branch -- Q2_0 for
  ternary weights is not in mainline llama.cpp) for the two Bonsai variants.
  Neither recipe file was added to `spacepilot/registry/runtimes/` in this

  <variant-id> --yes` then the L2R Gate 3 typed-task suite, same as the
