## Everything in `outputs/` is a mock

Every video job in `outputs/` has **`is_mock: True`** in its metadata. The checksums
confirm it: 7 files share one MD5, 6 share another — different prompts, byte-identical
video. They are 1–2s, 1024×576, 15.7KB, from prompts like `"auth smoke"` and
`"browser auth smoke"` left over from testing the token gate.

`/api/generate` falls back to a local mock when no GPU is running (README, API table).
That fallback is what produced all of it.

The 4K files in `outputs/` are mocks that went **through** the upscale chain, so they
do prove the CoreML upscaler and the compositor work end to end. The source frames
were never generated by LTX.

**Consequence:** pluto has never rendered a real video that survived to disk. The
LTX-2.5 worker, `pluto launch`, and the whole spot lifecycle exist and are untested
against a real render from this repo.

## Veo 3.1 comparison

18 real Veo clips sit in `~/Downloads/flow-batch3/` — 1280×720, 8.0s, 192 frames,
5–6 MB, generated through Google Flow.

| | LTX-2.5 | Veo 3.1 (Flow) |
| --- | --- | --- |
| Resolution | 1024×576, letterboxed | 1280×720 full frame |
| Duration | 5.04 s | 8.0 s |
| Cost per clip | **$0.013** marginal | $0.15 API (Lite) / free via Flow credits |
| Watermark | none | **"Veo" burned in** |
| Scriptable | yes | API only; Flow is manual |

**Visual read** (night-market shot on both sides): Veo wins clearly on raw fidelity —
rain, lantern detail, wet-road reflections, sharp background vendors. LTX honoured a
much harder compositional prompt (a luxury car nosing through a parting crowd, steam,
umbrellas) and delivered a deliberate 35mm anamorphic film look with real grain.
Different tools, not strictly better and worse.

### The economics

Veo API is $0.15 per 5s clip (Lite, no audio). The g6e.2xlarge spot box is $0.75/hr
flat, and LTX renders a clip in ~21s, so the box does ~171 clips/hour.

**They cross at 5 clips per hour.** Below that, the Veo API is cheaper and deletes the
entire launch/warm/terminate lifecycle. Above it, LTX pulls away fast — 50 clips is
$0.75 on the box against $7.50 on Veo.

The Flow watermark disqualifies Flow output for anything shipped, so "free via Flow"
is a quality-evaluation path, not a production one.

## Open, and not to be re-derived

- `/api/director/auto-script` returns five hardcoded scenes and ignores `topic`,
  `target_duration` and `style`. Docstring carries the TODO. Finishing it makes the
  route spend compute, which means `Depends(require_token)` and removal from
  `UNGATED_BY_DESIGN` — and the route guard exempts it by name, so nothing will flag it.
- `spacepilot/enhance_prompt.py` loads Qwen2.5-1.5B through transformers on MPS and is called
  by nothing. `/api/enhance` is rule-based string concatenation. Two divergent paths,
  the LLM one orphaned. Point both at the fleet in `INFERENCE.md` instead.
- No CI ran on PR #1. `.github/workflows/tests.yml` reported no checks — confirm it
  fires on pull requests before relying on it.
- **Pluto is not on the launch path.** The studio is the product, and the AI Director
  concept is specced in `motionvector/web/docs/agentic-studio-direction.md`. Do not
  grow a second director, or a second provider router, inside this repo.
