Spec, four behaviors

1. Thinking off by default

--thinking off|on. Off passes enable_thinking=False when the template accepts it. On is explicit, and the token cap has to cover the trace. No effort ladder.

2. A think-only transcript is a failure

Non-empty is not an answer. If the cap ends inside an unclosed <think>, exit non-zero. Keep the speed number. LFM’s template does not honor the flag. The weights write the tag themselves.

3. Ready means this MLX can load it

Import mlx_lm.models.<model_type> before the plan says ready. Bonsai was marked ready, then the child exited 1. Registry notes drift. The installed package does not.

4. The download bar tracks bytes

Xet writes one large .incomplete shard, so the bar sits at 0% and then jumps. Count those bytes. One overwritten line, not a new line every tick.

Later — the thesis, still gated

VISION and the build plan agree on the order. None of this starts while the CLI still records a non-answer as success.

  1. Fit before download. The plan already says what fits. Bonsai showed the gap: the plan said ready, the child could not load.
  2. Rank routes. Warm local above a priced API when the numbers say so, and show why. Phase 3. The warm half can land before any provider.
  3. One router, not N provider drivers. Phase 2. LiteLLM is a declared dependency that no shipped code imports. Money stays loud: price before, actual after. The build plan says this waits until Saurabh is in the room.
  4. Send work to another machine, then a dock. The daemon can see peers and cannot dispatch. No dollar budget exists yet. A dock does not start before that.
  5. SpaceBar voice, read-only. Duplex voice on Apple’s on-device model, then Core AI, then a rented box. The menu bar app must not change daemon state until that rule is lifted in writing. #122 and #134 are the open drafts.
  6. Cockpit stops inventing numbers. Phase 0.4 is still the written bug list. ui/ exists and is not what the server serves. Whether it replaces web/ is still an open call. No agent rewrites marketing copy.

Leave alone

  1. One-shot process. Load, answer, exit, memory returns. A resident server fights that.
  2. The 256-token safe cap. Reasoners ask for more by turning thinking on, not by raising the default.
  3. The default model. Changing it off Qwen3-8 is a product choice, not part of making the command honest.
  4. Stdin, a system message, and --json. Later, for agents. Not what made these runs lie.
