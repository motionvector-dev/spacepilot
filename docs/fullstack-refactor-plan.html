🛡️ Quality Assurance & Zero-Regression Protocol

To prevent breaking audio normalization, video ffmpeg mastering, or GPU worker handshakes, this refactor uses a surgical extraction model rather than a blind rewrite.

1. Logic Preservation (Lift & Shift)

FFmpeg flags, 2-pass LUFS normalization, ProRes mastering, Kokoro ONNX voice generation, and GPU auth remain byte-for-byte identical.

2. Step-by-Step TDD Gate

Baseline 42 tests verified first. Extract one module at a time and gate progress on 100% test pass rates before proceeding.

3. Strangler Fig UI Pattern

Existing vanilla studio stays fully live while the React app is built in parallel under /ui, ensuring zero downtime.

Agentic & Production Readiness

4A Event-Driven Jobs

Replace polling with Server-Sent Events (SSE):

Python routes/jobs.py 
# routes/jobs.py
@router.get("/api/jobs/{job_id}/stream")
async def stream_job(job_id: str):
    async def event_generator():
        while True:
            job = job_manager.get(job_id)
            yield {"data": job.model_dump_json()}
            if job.status in ("completed", "failed"):
                break
            await asyncio.sleep(1)
    return EventSourceResponse(event_generator())

Frontend uses EventSource or TanStack Query's SSE adapter — no more setInterval polling.
