1. Design Reference Audit (Runway ML Comparison)

Pattern Runway ML Implementation Pluto Studio Target Mapping
Left Nav Sidebar Persistent icon rail (56px) expandable to 240px with label drawers. Replace existing slideout config drawer with persistent interactive nav rail.
Top Header Minimalist header: Session title + Credits pill + Upgrade CTA + Menu. Strip down bulky header; delegate workspace navigation entirely to left sidebar.
Hero Prompt Area Large prompt box with media tags, Tab-to-complete, Ask/Quality popovers. Build universal prompt component for Home & Create workflows.
Skills Ecosystem Slash commands (/Ad, /MoodBoard) with thumbnail browser & Skill Builder. Introduce Pluto skills (/T2V, /I2V, /Upscale, /Loop, /Director) with custom skill builder.
Agent Sidebar Panel Multi-turn interactive Q&A cards with reasoning traces & question pagination. Upgrade right panel into conversational AI Director agent with visual wizard cards.

3. Key Component Specs

Interactive Modules

components/nav-sidebar.js components/prompt-bar.js components/skills-drawer.js components/agent-panel.js components/gen-prefs.js

Universal Prompt Bar

Self-expanding multi-line textarea with attached reference tags, Tab auto-complete, Ask/Quality selector, and slash command dispatcher.

Agent Decision Panel

Collapsible thought/reasoning traces ("Thought for 5s >"), wizard choice cards with radio inputs, and live storyboard diff patches.

Skills & Starter Drawer

Media asset picker tabs + skill catalog drawer + "Create Skill" modal with instruction length validators.

4. Phased Implementation Roadmap

1

Phase 1: Layout Foundation & Sidebar Navigation

Rebuild sidebar into collapsed/expanded navigation rail, streamline top header to minimal chat header, and update grid containers across all pages.

2

Phase 2: Home Page Creative Hub & Universal Prompt Bar

Redesign home.html into hero greeting with category filters, example starter cards, and interactive prompt bar module.

3

Phase 3: Agent Panel, Conversational Storyboard & Skills System

Build right-side conversational AI Director panel with reasoning expanders, choice wizard cards, and skills modal.

4

Phase 4: Timeline Glassmorphism & System Polish

Refine bottom NLE timeline chrome, add glassmorphism toolbars, persist recent session thumbnails, and run regression tests.
