## 1. Executive Summary

Today we successfully transitioned the SpacePilot web surface from monolithic vanilla HTML/CSS/JS files into a production-grade, modular, typed **React 19 + TypeScript + Vite + Tailwind v4** application suite.

All hardcoded mock arrays, fake timers, and simulated states have been replaced with **TanStack React Query v5** reactive hooks, typed mutations, and live bi-directional WebSocket PTY bridges connected to the FastAPI backend.

## 6. Local Quickstart for Incoming Developers

To run the full stack locally:

```bash
# Terminal 1: Start FastAPI Backend (Port 8088)
cd /Users/saurabh/code/motionvector/pluto
python3 -m uvicorn src.web_api:create_app --factory --port 8088 --host 0.0.0.0

# Terminal 2: Start React Frontend (Port 5173 with proxy to 8088)
cd /Users/saurabh/code/motionvector/pluto-frontend/ui
pnpm dev --port 5173
```

Then visit:
* `http://localhost:5173/create` — Video Generation Wizard
* `http://localhost:5173/cockpit` — GPU Spot Telemetry & Web SSH
* `http://localhost:5173/studio` — Runway & Vibe Studio
* `http://localhost:5173/docs` — Developer Reference & Live Probe
* `http://localhost:5173/admin/oven` — Swarm Kanban Matrix
