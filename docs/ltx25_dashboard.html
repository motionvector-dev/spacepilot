Pluto CLI Architectural Audit Findings

        

          
            

              Severity
              Component
              Issue & Risk
              Remediation Strategy
            

          
          
            

              RESOLVED
              src/ltx_worker.py
              Duplicate Pipeline VRAM Allocation: load_i2v_model() was loading a second 28GB model copy into CUDA, causing OOM on 48GB cards.
              FIXED: LTX2ImageToVideoPipeline now shares transformer, text_encoder, tokenizer, vae, scheduler, and vocoder from the resident t2v pipeline — zero duplicate VRAM.
            

            

              RESOLVED
              setup_ltx_ec2.sh
              Torch/ScalingType Incompatibility: DLAMI ships torch 2.7 which lacks ScalingType required by diffusers 0.40.0.dev0.
              FIXED: Setup now upgrades torch>=2.12 torchvision torchaudio after pip install. torchao removed (unused, caused breakage). HF_TOKEN defaults to None for public models.
            

            

              RESOLVED
              infra/gpu-box.sh
              Wrong AWS Profile: Hardcoded antigravity-dev-user lacks ec2:CreateTags permission, blocking instance launch.
              FIXED: Default profile changed to default (saurabh, full IAM). Applied to gpu-box.sh, cli.py, and SSH config.
            

            

              RESOLVED
              infra/gpu-box.sh
              Security Group Blocked: pluto-gpu-sg had zero inbound rules — SSH (22) and worker (5000) both unreachable.
              FIXED: Added inbound rules for TCP 22 and 5000 from 0.0.0.0/0.
            

            

              RESOLVED
              setup_ltx_ec2.sh
              Root Disk Overflow: HF cache (83GB) wrote to root disk (6.7GB free) because HF_HOME wasn't set in worker startup env.
              FIXED: Worker startup now exports HF_HOME=/scratch/hf so cache stays on 217GB NVMe.
            

            

              RESOLVED
              pipeline scripts
              Wrong Interpreter: Scripts called python bin/pluto but bin/pluto is a bash script, not Python.
              FIXED: All scripts now use bash bin/pluto.
            

            

              MAJOR
              src/cli.py
              Missing LTX-2.5 Controls: CLI lacks flags for STG, modality scale, negative prompt, audio guidance, and upscaling.
              Add CLI flags to cmd_generate and pass them through the HTTP JSON payload.
            

            

              MAJOR
              src/ltx_worker.py
              Rigid Concurrency Rejection: Rejects overlapping requests with 409 Conflict rather than using a task queue.
              Implement a lightweight FIFO job queue thread in Flask worker.
